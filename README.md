# 🛣️ PotholeVision — Municipal Infrastructure Monitoring & Defect Detection System

> **An AI-powered road inspection platform built with MobileNetV2, TensorFlow/Keras, and Streamlit.**  
> Upload road photos, detect potholes instantly, run batch audits, and visualize incidents on a live GIS map — all from a production-ready web UI.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 🔍 **Single Image Diagnostic** | Upload a road photo and get instant AI classification with confidence score, defect area %, and hazard tier |
| ⚠️ **Severity Engine** | Automatically rates each detection as Critical Hazard, Moderate Hazard, or Minor Defect with actionable maintenance recommendations |
| 📁 **Batch Audit & CSV Export** | Upload dozens of road photos at once; generates a full incident log and one-click downloadable CSV report |
| 🗺️ **Municipal GIS Incident Map** | Interactive map tracking reported road hazards across 8 global cities with severity overlay |
| 🧠 **MobileNetV2 Deep Learning** | Fine-tuned on ~5,000 real road surface images — test accuracy **98.49%** |

---

## 🧠 Model Performance

| Metric | Score |
|---|---|
| **Accuracy** | 98.49% |
| **Precision** | 98.78% |
| **Recall** | 98.17% |
| **F1-Score** | 98.47% |

## 🛠️ Setup & Run Instructions (Windows / VS Code)

### Prerequisites
- Python 3.10 or 3.11
- Git
- VS Code (recommended)

### Step 1 — Clone the Repository

```powershell
git clone https://github.com/YOUR_USERNAME/potholedetection.git
cd potholedetection
```

### Step 2 — Create & Activate Virtual Environment

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### Step 3 — Install Dependencies

```powershell
pip install -r requirements.txt
```

### Step 4 — Download & Prepare Dataset

Download the dataset from [Zenodo](https://zenodo.org/records/13334878), extract it into the project root, then run:

```powershell
python src/prepare_data.py
```

This will:
- Scan the raw images
- Remove duplicates using MD5 hashing
- Split into `dataset/train/`, `dataset/validation/`, `dataset/test/` at a **70:10:20** ratio

### Step 5 — Train the Model

```powershell
python src/train.py
```

- Phase 1: Trains only the classification head (frozen MobileNetV2 base)  
- Phase 2: Fine-tunes the top 40 layers of MobileNetV2  
- Saves model to `models/pothole_mobilenetv2.keras`  
- Training time: ~12–15 minutes on a modern CPU

### Step 6 — Evaluate the Model *(optional)*

```powershell
python src/evaluate.py
```

Outputs accuracy, precision, recall, F1-score, and saves the confusion matrix to `reports/`.

### Step 7 — Launch the Web Application

```powershell
streamlit run app.py
```

Open your browser at **http://localhost:8501**

## 🌐 Application Tabs

### 🔍 Tab 1 — Single Image Diagnostic
- Upload any road photo (JPG/PNG) or select a pre-loaded sample from the sidebar
- AI classifies as **POTHOLE DETECTED** or **NORMAL ROAD SURFACE**
- Shows: Confidence Score, Defect Area %, Hazard Tier, Pothole Risk Index, Normal Road Index

### 📁 Tab 2 — Multi-Photo Batch Audit & Export
- Upload multiple road photos at once
- Generates an **Incident Master Table** with Classification, Severity, Confidence, and Defect Area per image
- One-click **CSV download** (`roadguard_pothole_inspection_report.csv`)

### 🗺️ Tab 3 — Municipal GIS Incident Map
- Select from 8 global city presets or enter custom GPS coordinates
- Interactive map with 20 simulated pothole incident markers
- Incident Registry table with Severity and Confidence columns

**Supported Cities:**
Mumbai · Delhi NCR · Bengaluru · New York · London · San Francisco · Tokyo · Sydney

## 📊 Severity Classification

| Tier | Condition | Action |
|---|---|---|
| 🔴 **Critical Hazard** | Confidence > 85% or Defect Area > 30% | Immediate emergency repair required |
| 🟡 **Moderate Hazard** | Confidence 65–85% | Schedule routine patching within 7 days |
| 🟢 **Minor Defect** | Confidence < 65% | Monitor — add to watch list |
